# 合同方案：选题 → 系统讲义 → 系统成片（相对 `prd-explain-video-v1.md` 的流程修订）

- 状态：**已拍板**（默认能力档 `defaultAbilityBandId=L2`；成片须烧入板书；讲义默认 AI+覆盖闸门）
- 日期：2026-08-11
- 依据：`docs/prd-explain-video-v1.md`（硬约束 C1–C4、D11、答案权威）+ 用户拍板：「只选题；讲义与视频由系统生成；不允许硬代码」；反馈：禁止纯语音空画面、禁止固化套话讲义
- 性质：产品合同（可验收）；**不含**实现排期与技术说明书

---

## 1. 合同目标

教师**唯一必做动作 = 选题**（来源 A：试卷已有题）。系统据此自动生成讲义，再根据讲义自动生成动画视频。主路径为一键流水线；失败须显式可见。禁止硬代码特例（C1）。

---

## 2. 用户主路径（合同流程）

| 步骤 | 谁操作 | 输入 | 输出 | 通过条件 |
|------|--------|------|------|----------|
| **① 选题** | 教师 | 来源 A：卷内已有题 | 「练习包」已绑定该题 | 题可读；**选题即授权**使用卷内标答与 `solution_steps` 作为讲解依据（不要求单独「锁定」按钮；内部可记 `lockedAt=选题确认时刻` 供审计，**对用户不可见技术词**） |
| **② 系统生成讲义** | 系统（自动） | 已选题 + 卷内标答/步骤 + **配置声明的默认能力档** | 「讲义」：讲解稿 + 板书结构 | 标答与步骤完整（C2）；讲义结构/一致性闸门通过；失败 → **显式失败**，不得编造答案 |
| **③ 系统根据讲义生成动画视频** | 系统（自动） | **讲义就绪闸门已通过**的讲义快照 + 同一能力档硬约束 | 可播放成片 | 讲义失败则**不成片**（C3）；成片失败 → 显式失败、**无播放 URL**；禁止「没视频也算成功」 |
| （可选）预览讲义/视频 | 教师 | 讲义或成片产物 | 预览 | 非主路径必点；失败用中文短句提示 |

**主操作约定**：选题后**一次主操作**即可进入流水线（②→③ 自动串联）。界面**不得**把「锁定题目」「确认讲义」「选能力档」作为主路径必点步骤；上述可进高级/可选，默认不挡一键流水线。

**能力档（写死）**：主路径**不**要求教师点选。系统必须使用配置键 **`defaultAbilityBandId`**（建议落在 `explain-video.json`）所声明的档位 id；该 id **必须**存在于配置的 `abilityBands`。禁止按题干猜档；禁止静默空档成片。缺键或 id 无效 → **拒入队/显式失败**。

**内部闸门（对用户可折叠，合同不削弱）**：即使 UI 不展示「确认讲义」，系统仍须在**讲义就绪闸门通过后**才允许成片；禁止跳过讲义成功态直出播放 URL。

**来源 B（自定义规格）**：标为**本版次路径 / 延后**。本版主路径只保证「选题 → 系统讲义 → 系统成片」。

**学生侧**：仅能打开教师已发布且成片为「可播放」的条目；不暴露中途态与内部码。

**答案权威（不得削弱）**：

- 来源 A：缺标答或 `solution_steps` → **拒生成讲义**（显式失败），不得编造（C2）。
- 选题 = 授权使用该题卷内标答与步骤；不再要求单独「锁定」主按钮。

---

## 3. 硬约束（继承且本版不削弱）

| 编号 | 合同要求 |
|------|----------|
| **C1** | 禁止硬代码：分类骨架、能力档、闸门、时长字数、默认档位等只进配置 / `schemas` / 数据面；**禁止**单卷单题特例进 `src/lib` |
| **C2** | 不瞎猜：缺标答/`solution_steps` → 拒讲义；能力档仅配置默认 id，禁止猜档、禁止空档成片 |
| **C3** | 讲义失败不成片；成片失败无播放 URL；禁止没视频标成功；禁止静默降级 |
| **C4** | flag 关闭时现网主路径不受影响（继承原 PRD） |
| **D11** | MySQL 存元数据 + 路径；成片文件落配置目录（如 `public/explain/`），**非 BLOB** |

## 4. 与现状差异

| 维度 | 原合同/向导倾向 | 本版合同（已拍板） |
|------|-----------------|-------------------|
| 教师必做 | 选题 + 锁定 + 选档 + 确认讲义 + 成片 | **仅选题**；其余系统自动 |
| 主路径顺序 | 选题 → 讲义 → 审阅确认 → 成片 | **选题 → 系统讲义 → 系统成片**（一键） |
| 能力档 | 教师必选 | **配置 `defaultAbilityBandId`**；选档仅高级可选 |
| 「锁定」 | 主路径按钮 | **选题即授权**；内部可记 `lockedAt`，UI 不暴露技术词 |
| 讲义确认 | 主路径必点 | **默认不要求点确认**；内部仍须讲义就绪闸门通过后成片 |
| 来源 B | 可与主路径并列 | **次路径/延后** |
| 失败 | 显式（C3） | 保持且强化：无视频不得标成功 |

## 5. 状态机（用户可见中文名 ↔ 内部状态码）

默认层只展示中文名；内部码禁对学生/教师默认层直出。

| 用户可见 | 内部状态码（建议） | 含义 | 允许的下一动作 |
|----------|-------------------|------|----------------|
| 草稿包 | `draft` | 已选题，答案权威未齐 | 补全卷内标答/步骤后重试；满足后可一键流水线 |
| 生成讲义中 | `generating_handout` | 系统正在生成讲义 | 等待；禁止标可播放 |
| 讲义就绪 | `handout_ready` | 讲义闸门通过（可对用户折叠进「成片中」前一瞬） | 自动进入成片；高级可预览讲义 |
| 成片中 | `queued_render` | 按已就绪讲义合成中 | 等待；禁止标可播放 |
| 可播放 | `ready` | 成片成功且有有效播放路径 | 预览 / 布置（布置可后续里程碑） |
| 失败 | `failed` | 讲义或成片任一步显式失败 | 显式重试；**禁止**直接变「可播放」 |

**合法转移（合同）**：

- 禁止：跳过讲义就绪 → `可播放`
- 禁止：`失败` → `可播放`（无重试成功）
- 禁止：讲义未过闸门写播放 URL
- 禁止：无有效 `defaultAbilityBandId` 入队成片

原 `awaiting_teacher_lock` / `awaiting_handout_confirm`：**主路径不再要求对应必点 UI**；答案权威改由「选题授权 + 标答/步骤完整性闸门」承担；讲义确认改为内部「讲义就绪」闸门。

## 6. 验收标准（可勾选）

### 6.1 主路径（正面）

- [ ] 教师选题后**一次主操作**进入流水线：系统生成讲义 → 系统成片 → 「可播放」且可预览。
- [ ] 主路径**无**必点：「锁定题目」「确认讲义」「选能力档」。
- [ ] 选题即授权使用卷内标答与步骤；内部可记 `lockedAt`，默认层无技术词。
- [ ] 能力档取自配置 **`defaultAbilityBandId`**，且该 id 在 `abilityBands` 中存在。
- [ ] 来源 A 缺标答或 `solution_steps`：拒生成讲义，不编造。
- [ ] 讲义失败 → 「失败」，不成片、无播放 URL。
- [ ] 成片失败 → 「失败」，无播放入口，不得标讲解完成。
- [ ] 成片元数据与路径在 MySQL；文件非 BLOB（D11）。
- [ ] flag 关闭时现网不受影响（C4）。
- [ ] 分类骨架/档位/闸门/时长字数/默认档仅配置或 schemas，无单卷单题硬代码（C1）。

### 6.2 负面验收（必须卡住）

- [ ] 未过讲义就绪闸门不得成片、不得写播放 URL（即使 UI 无「确认讲义」按钮）。
- [ ] 缺 `defaultAbilityBandId` 或 id 无效 → 拒生成，禁止猜档/空档成片。
- [ ] 禁止硬编码单卷/单题进 `src/lib`（C1）。
- [ ] 禁止静默降级、空成功、没视频标完成（C3）。

## 7. 非目标（本版不做）

1. 数字人出镜、整卷长片、实时互动答疑。
2. 按题干猜能力档、无标答瞎猜答案、静默空档成片。
3. 成片失败改交「仅讲义」并标记成功。
4. 来源 B（自定义规格）主路径交付（本版延后）。
5. 另起平行命题台替代 `/generate`。
6. 家长独立 App、跨学期错题本大而全。
7. 为凑本功能修改 OCR / 识图网关语义。
8. 将「锁定 / 确认讲义 / 选档」重新做成主路径必点步骤。

## 8. 已决决策（原开放项 Q1–Q3 收口）

| 原编号 | 已决 | 合同含义 |
|--------|------|----------|
| **Q1** | **选题即授权** | 不再要求主路径「锁定答案」按钮；选题确认时刻可写内部 `lockedAt`。来源 B 延后，本版不约定其锁定 UI。 |

## 9. 风险与依赖（一句话）

- **答案错误进片**：选题授权 + 标答/步骤完整性拒入 + 讲义一致性闸门；运营抽检。
- **默认档误配**：缺键/无效 id 须显式失败，禁止猜档顶上。
- **TTS / ffmpeg**：未就绪则拒成片并中文说明；禁止静默改引擎。
- **MySQL**：flag 开且库不可用则入口不可用或拒入队（D11）。
- **用户误解阶段**：默认层中文阶段名；可选预览；失败一句可行动原因。
