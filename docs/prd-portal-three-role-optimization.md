# 需求优化：门户三角色（运维 / 教师 / 学生）

- 状态：**范围已冻结**（用户确认 2026-08-10）
- 依据：仓库代码与既有 PRD（`prd-account-three-portal.md`、`prd-classroom-class-workbench.md`、`prd-classroom-auto-grade-wrong-drill.md`、`account-and-machine-setup.md`），**禁止臆测未实现能力**
- 约束延续：禁止按邮箱/题号/试卷 ID 硬编码；年级/学科仅配置枚举；不伪造用时与分数；不改动既有阅卷 schema 语义

### 已拍板决策

| # | 决策 | 结论 |
|---|------|------|
| 1 | 教师一级导航 | **维持「班级为容器」**（不改年级树一级 IA） |
| 2 | 布置权限 | **只认班内名册**；运维师生学科链接不自动进班、不替代名册 |
| 3 | 教师建号边界 | **可建学生**；**不可改非本班学生**（改档/设密须为本班成员） |
| 4 | 布置向导 | **不冻结流程**，允许优化交互与可读性 |
| 5 | 验收环境 | **本机 MySQL 账号 + 本机课堂 JSON 为主**；云端仅冒烟 |

## 2. 需求优化后的范围（建议拍板版）

原则：**优先补齐半具备与体验债，不推翻班级工作台**；用户口语中的「年级树」映射为「学段/年级组织班级 + 班内按年级选卷」，除非决策题改拍。

### Epic A · 运维端

| 项 | 内容 |
|----|------|
| **目标** | 运维可增删改师生账号、维护师生对应与学科、管理课件目录入口；当前身份为运维时不混入师生门户 |
| **验收口径** | ① 创建含教师/学生身份账号（年级/学科走配置枚举）；② 建立/修改/解除师生关系并绑定学科；③ 停用/启用、重置密码可用；④ `activeRole=admin` 时顶栏无课堂/作业入口 |
| **非目标** | 运维代批作业、全库发布大盘、Excel 批量导入、自助注册 |
| **依赖** | 本机账号表就绪或云端 Service Role（`getAccountAdminCapability`）；配库页 `/setup` |

### Epic B · 教师端

| 项 | 内容 |
|----|------|
| **目标** | 以班级进入工作台：布置/取消作业、定向学生、看提交进度与分数用时、错题巩固；可建/改本班相关学生账号（开关允许时） |
| **验收口径** | ① 创建班级（名称+年级）→ 作业/学生/作答三页签；② 布置向导内见本年级卷发布覆盖态，可选全体或定向学生；③ 作答名册含状态、得分、用时；**优化项**：列表可见错题题型摘要（消费已有 `wrongTypeCounts`）；④ 详情可看对错/标答对比（与阅卷结果一致，禁止伪造）；⑤ 错题巩固入口在有提交时可用 |
| **非目标** | 重建「全年级跨班试卷树」为一级导航（除非决策改拍）；手批改分、改交、CSV/正确率图表（已推迟） |
| **依赖** | 真实教师登录；班级与作业存储（MySQL/JSON 或云端）；试卷库有对应年级卷 |

### Epic C · 学生端

| 项 | 内容 |
|----|------|
| **目标** | 账号登录后查看作业（未完成优先）、作答、提交后见得分/用时/错题与正确答案 |
| **验收口径** | ① 仅学生身份可进 `/student`；② 列表按年级分组、学科筛选、未完成在前；③ 作答中不泄标答；提交后 `SubmissionGradeSummary` 展示得分与错题正确答案；④ 用时仅在有合法 `started_at`/`submitted_at` 时显示，否则「—」 |
| **非目标** | 改交；独立班级社交空间；家长查看 |
| **依赖** | 被定向或年级适用的作业；登录态与学生档案年级 |

### 口语合并与冲突纠正

1. 用户两个「三、」合并为：**教师端 Epic B**（登录 + 班内作业/发布/作答/错题）。
2. 「项目分为三端」→ **已落地**；本轮是体验与半具备补齐，不是从零分端。
3. 「年级树」→ **建议映射为现有班级+学段筛选+向导内按年级选卷**；若要真·年级树一级导航，须先改 PRD 再动 IA。
4. 「老师端也可维护学生」→ **已有**（建号/改档），须与运维权限边界在决策题中确认。

## 3. 信息架构与前端优化原则

对照 UI 宪法与 `ui-no-redundant-copy`：

1. **版心**：三端继续 `PageShell`（课堂/运维用 `full`）；页头短标题；禁止配库页「左状态+右步骤」硬套到课堂。
2. **教师端选型（建议保持）**  
   - 一级：班级列表（学段筛选 = 轻量「树」感）  
   - 二级：班内单层 Tabs「作业 / 学生 / 作答」  
   - 选卷与发布态：仅在「布置作业」向导内（符合班级 PRD，避免作业页与卷库双列表）  
   - 作答：左作业列表 + 右名册（已有），**补一列错题题型**即可，勿再加百科式说明文案  
3. **学生端**：保持作业列表主任务；账号改密进 Sheet；空态一句「暂无作业」。
4. **运维端**：顶栏 Tabs「账号 / 师生关系 / 课件」已清晰；技术栈提示仅缺配时出现，勿常驻过程旁白。
5. **固定壳**：沿用全站 Header + main 滚动 + Footer；打印/作答细节遵循现有 `no-print` 约定。
6. **禁止**：为「解释系统如何排序/筛选」增加常驻文案；禁止硬编码样例账号/班级 ID。
