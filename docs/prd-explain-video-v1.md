- 角色：产品方案收口；实现须另拆 WBS，**不得**在本 PRD 未决项上猜测开工

| # | 约束 | 口径 |
|---|------|------|
| C1 | **不允许硬代码** | 题型骨架、能力档、闸门、提示词键、时长/字数、存储键模板、官方规格目录 → 仅配置 / `schemas` / 数据面；禁止试卷 ID、题目 ID、校名、单册章节特例进 `apps/web/src/lib` 业务分支 |

## 0. 一句话产品定义

教师通过**单一向导**产出「题型练习包」：**题目 + 已锁定标准答案与步骤 + 指定能力档的讲解成片**；学生仅播放状态为 `ready` 的讲解，并在教师设定的节奏下练习。

---

## 1. 目标与非目标

### 1.1 目标（v1 必须交付）

1. **双来源、单向导**  
   - 来源 A：已有试卷中的题目（须已有完整标答与解析步骤）。  
   - 来源 B：教师填写**版本化题型规格** → 系统生成题目、答案、步骤 → **教师显式锁定**。  
2. **按配置能力档生成讲解脚本与成片**（板书逐步呈现 + 口播合成；非数字人）。  
3. **按题成片、按人选档**：同一题每种能力档最多一份成片；学生只绑定观看哪一档，禁止按学生人数重复渲染。  
4. **全程可审计**：规格版本、题目引用、锁定人/时间、能力档、脚本、成片、job 状态、模型用途、失败原因。  
5. **Feature flag 关闭时现网零回归**。

### 1.2 非目标（v1 明确不做）

1. 数字人出镜、整卷长片、实时互动答疑。  
2. 无锁定的自动「高置信锁答」、无依据的自动升降能力档。  
3. 成片失败时改交「仅脚本/翻页」并标记成功（违反 C3）。  
4. 另起平行「命题台」与 `/generate` 抢入口；本能力定位为**练习包 + 讲解**，非整卷命题替代。  
5. 家长独立 App、跨学期错题本大而全。  
6. 修改现有 OCR / 识图网关语义来「凑」本功能。

## 2. 已决决策表

| # | 议题 | 已决口径 |
|---|------|----------|
| D1 | 产品形态 | **一个向导**；题目来源为向导第一步选项（A 已有题 / B 新规格），不是两套页面 |
| D2 | 讲解形态 | MVP = **数字板书 + 口播成片**；脚本为权威中间态（ExplainScript IR） |
| D3 | 能力档 | 配置枚举 + **硬约束表**（时长、字数、禁用术语等）；闸门按表校验；**无默认猜档**——须教师选择或读取已落库学情字段 |
| D4 | 答案权威 | 来源 A：卷内标答与 `solution_steps` 必须完整否则拒讲；来源 B：**教师锁定前禁止**脚本/成片/对学生揭示为正式标答 |
| D5 | 可判定 vs 开放 | 配置声明题型是否 `requiresTeacherLockAlways`；凡开放解答/证明类 → 必须人锁；可判定类仍须人锁（v1 不设自动锁） |
| D6 | 失败策略 | Job 显式 `failed`；不写播放 URL；可显式重试为新作业或同 job 的 `retry` 动作，禁止静默改写成功 |
| D7 | 成本 | 默认 1 题 × 1 档；多档/批量须二次确认；按题渲染 |
| D8 | 开关 | 配置项启用（名称实现时入配置，禁止魔法字符串散落）；默认 off |
| D9 | 模型 | 出题与讲解为**不同用途**（配置映射到模型目录用途键）；禁止与命题用途隐式混用且无配置 |
| D10 | 治理 | 新增源码纳入通用内容政策扫描；禁止单卷单题硬编码 |
| D11 | **持久化默认面** | **默认 MySQL**：`ItemTypeSpec` / `PracticeItem` / `ExplainScript` / `ExplainJob` / `ExplainAsset` 元数据（含播放指针、校验和、状态、锁定信息）均写入 MySQL（表结构进项目 `sql/mysql` 约定迁移，禁止第三套私藏库）。**成片二进制不进 BLOB**：文件落在配置声明的本机目录（与听力音频、`import-figures` 同类），MySQL 只存路径/键与校验信息。MySQL 不可用且本能力 flag 为 on 时 → **拒入队/入口不可用**（C3，禁止静默改写本地 JSON 充数）。 |

## 3. 用户流程

### 3.1 教师向导（主路径）

```text
① 选来源（A 已有题 | B 题型规格）
② 产出或载入「题目 + 答案 + 步骤」
③ 教师确认并锁定（B 必锁；A 若缺步骤则阻断并提示补全，不编造）
④ 选择能力档（配置列表，必选）
⑤ 入队：脚本生成 → 脚本闸门 → 成片
⑥ 仅 ready 可预览；通过后布置 / 发给学生
```

任一步不满足前置条件 → **阻断**，文案说明缺什么（零技术词默认层；运维细节进高级/日志）。

### 3.2 学生

- 仅能打开教师已发布且讲解 job=`ready` 的条目。  
- 作答与看讲的先后由作业设置字段控制（配置枚举，如 `practice_first` / `explain_allowed`）；未配置的合法枚举值不得猜测为可看讲。  
- 不展示内部 job/模型名。

### 3.3 题型规格（来源 B）

规格为**结构化、schema 校验**的数据对象，可保存为「我的模板」（仍是数据，不是源码）。  
官方提供的骨架列表来自**配置目录**，自定义 = 基于骨架填知识点/难度/约束等字段；禁止在源码写死某省某册。

必填字段（逻辑名，具体 JSON 进 schema）：

- 学科、年级（与课程目录 ID 对齐，不得自由正文冒充 ID）  
- 骨架 ID（配置内存在）  
- 知识点引用（目录内合法）  
- 难度枚举（配置内）  
- 生成数量（配置上下限内）  
- 约束结构化字段（数域、是否允许配图需求等，按骨架 schema）

自由补充说明：可选；不得单独作为唯一规格输入绕过 schema。

## 4. 数据与状态机

### 4.1 核心对象（逻辑）

| 对象 | 说明 |
|------|------|
| `ItemTypeSpec` | 版本化规格（`specId` + `revision`） |
| `PracticeItem` | 题目 + 答案 + 步骤；含 `lockedAt` / `lockedBy` |
| `ExplainScript` | 分镜 IR，schema 校验 |
| `ExplainJob` | 脚本/成片任务与状态 |
| `ExplainAsset` | 成片**存储键/相对路径**与校验和（MySQL 行）；仅 `ready` 时存在有效播放指针；二进制在配置目录内 |

字段级 schema / 表结构实现时落入 `schemas/v1/` 与 `sql/mysql` 约定，本 PRD 不臆造列类型。业务行默认只认 **MySQL（D11）**。

### 4.2 状态机（禁止兜底）

```text
draft
  → generating_item          （仅来源 B）
  → awaiting_teacher_lock
  → queued_script
  → script_ready
  → queued_render
  → ready
  → failed                   （终态之一；可显式 retry）
```

合法转移表实现时单测锁死；**禁止**从 `failed` / `awaiting_teacher_lock` 直接标 `ready`。

### 4.3 脚本 IR（逻辑要求）

每幕至少包含：目的枚举（配置）、口播文案、板书/公式文本、可选附图引用（必须是题目已有 `figure_refs` 内 ID，禁止臆造 URL）。  
硬约束：口播长度、幕数、总时长上界来自**能力档配置**，超限闸门失败。

---

## 5. 闸门（Fail closed）

| 阶段 | 必须通过 | 失败行为 |
|------|----------|----------|
| 启用检查 | flag on；模型用途已配置；TTS/合成依赖探测通过 | 入口不可用或拒入队，说明原因 |
| 来源 A | 题目存在；标答非空；步骤非空且可读 | 拒讲 |
| 来源 B | 规格 schema 通过；生成结果 schema 通过 | job/`generating_item` → failed |
| 锁定 | 存在 `lockedAt` | 拒脚本 |
| 能力档 | 枚举合法；若用学情字段则字段存在且合法 | 拒脚本 |
| 脚本 | IR schema；与锁定答案/步骤一致性规则（配置） | 不成片 |
| 成片 | 渲染成功；产物可读；写入资产指针 | `failed`，无播放 URL |

一致性规则实现必须配置化/可测，禁止「模型说一致就算一致」而无校验器。

## 6. 与现网集成（不破坏运行）

| 现网能力 | 集成方式 |
|----------|----------|
| 试卷/题目存储 | 只读引用已有题；新题与讲解业务行默认写入 **MySQL**（D11）；禁止第三套私藏格式；禁止 flag on 时用 JSON 文件冒充已落库 |
| 课堂作业 / 错题巩固 | 向导可从错题列表**带合法 question 引用**进入来源 A；不改变既有阅卷语义 |
| 模型目录 | 增加用途键映射（配置）；无映射则本能力不可用 |
| TTS | 复用项目已支持的 TTS 运维方式；未配置则拒入队（不静默改用未声明引擎） |
| 账号三角色 | 仅教师（及配置允许的角色）创建/锁定；学生只读 ready |

**关闭 flag 时**：不挂载教师向导路由入口（或入口隐藏），不注册消费队列，不要求合成二进制存在。

## 7. UI 纪律

- 向导一屏一主任务；主按钮单一（如「锁定并生成讲解」分步呈现，避免双主 CTA 对冲）。  
- 默认层零技术词（无 FFmpeg/Piper/env 名）；缺依赖时给学生/教师可行动短句，细节进高级或日志。  
- 禁止冗余常驻说明；空态一句。  
- 版心用现有 `PageShell` 体系，不另起色板。

## 8. 验收标准（分层，全部满足才算 v1）

### 8.1 现网安全

- [ ] flag off：现有主路径与约定测试不受影响；应用可正常启动。  
- [ ] flag on 但依赖未就绪：入口明确不可用；无未捕获异常/白屏。  

### 8.2 反硬编码 / 反瞎猜 / 反兜底

- [ ] governance：讲解相关新增代码通过通用内容政策扫描（无单卷单题硬编码）。  
- [ ] API：无 lock 请求脚本/成片 → 4xx；无合法能力档 → 4xx。  
- [ ] 故意破坏合成依赖 → job=`failed` 且无播放 URL。  
- [ ] 来源 A 缺步骤 → 拒讲且不生成假步骤。  

### 8.3 主路径

- [ ] 来源 B：规格 → 生成 → 锁定 → 选档 → `ready` 成片可播。  
- [ ] 来源 A：合法已有题 → 选档 → `ready`。  
- [ ] 同一题两档 = 两资产；两学生同档 = 同资产。  

### 8.4 内容

- [ ] 抽样：讲解结论与锁定标答一致（按配置一致性检查器）。  
- [ ] 抽样：L 档满足该档硬约束表。

## 11. 环境与配置（已冻结进仓库配置，禁止源码另猜）

1. **骨架/能力档/文案**：`apps/web/src/config/explain-video.json`（改配置不改业务分支）。  
2. **存储**：D11 — MySQL 元数据 + `public/explain/`（及 `apps/web/public/explain/` 同步）。  
3. **合成依赖**：`render.ffmpegBinEnv` / `ffmpegBinName`；`render.ttsEngine` 默认 `say`（可改为 `piper` 并配齐模型 env）。缺任一依赖 → 入口显示原因，拒入队。  
4. **开关**：`explain-video.json` → `enabled`（默认 `false`）。改为 `true` 后须已配库（含 `explain_practice_packages`）且本机 ffmpeg + TTS 可用。  
5. **作业看讲节奏**：M2；本版向导仅教师生成与预览。
